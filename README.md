# 📊 Telco Customer Churn Analysis

## 📌 Project Overview

Customer churn is one of the biggest challenges faced by telecom companies. This project analyzes customer behavior, identifies the factors influencing churn, and builds machine learning models to predict customers who are likely to leave.

---

## 🎯 Objectives

- Explore the Telco Customer Churn dataset.
- Clean and preprocess the data.
- Perform Exploratory Data Analysis (EDA).
- Build machine learning models to predict churn.
- Compare model performance.
- Analyze feature importance.
- Simulate churn cost and retention strategies.

---

## 📂 Dataset

**Dataset:** Telco Customer Churn

The dataset contains customer demographic information, subscribed services, billing information, and churn status.

### Target Variable

- **Churn**
  - Yes
  - No

## 📈 Results

The analysis identified several important factors affecting customer churn:

- Month-to-month contracts
- Customer tenure
- Monthly charges
- Tech support
- Online security
- Internet service type

Random Forest achieved better predictive performance, while Logistic Regression provided better interpretability.

---

## 💼 Business Recommendations

- Encourage long-term contracts.
- Improve customer onboarding.
- Enhance technical support.
- Offer personalized retention campaigns.
- Target high-value customers with loyalty programs.
- Use predictive analytics for early churn detection.
